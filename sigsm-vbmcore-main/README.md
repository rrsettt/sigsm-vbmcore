# S.I.G.M.S VBMCore

➤ Proyecto de Egreso realizado para el Hospital de Clínicas con el fin de optimizar procesos que actualmente generan un costo o no son eficientes.

En esta etapa del proyecto se desarrolla principalmente el Módulo de Documentación.


## Módulo de Documentación (📃)

- Portal web de documentación.
- Información sobre enfermedades y tratamientos.
- Gestión de documentos PDF.
- Encuestas para pacientes.
- Panel de administración para funcionarios.
- Acceso público al portal mediante código QR.


## Módulo de Seguimiento (🚑)

Actualmente en desarrollo.

Está pensado para realizar el seguimiento de traslados y gestionar la asignación de personal y pacientes.


## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Apache


## Instalación

1. Colocar el proyecto dentro de `htdocs`.
2. Iniciar Apache y MySQL desde XAMPP.
3. Importar `sql/VBMCoreDataBase.sql` desde phpMyAdmin.
4. Verificar la conexión en `datos/conexion.php`.
5. Acceder al proyecto mediante `http://localhost/`.


## Estado del proyecto

El Módulo de Documentación se encuentra funcional, incluyendo gestión de documentos, autenticación de funcionarios, portal público y encuestas.

El Módulo de Seguimiento se encuentra en desarrollo.
